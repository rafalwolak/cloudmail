# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Developers and installation administrators managing transactional email for their applications.

## Product Purpose

Cloudmail is an open-source transactional email service hosted on Cloudflare. Its API, MCP server and dashboard support sending, receiving and diagnosing email.

## Capabilities and Constraints

The existing vanilla HTML/CSS/JavaScript dashboard uses Better Auth administrator sessions. Preserve authentication, private message storage, template isolation, API permissions and the distinction between accepted messages and delivered recipients. Marketing campaigns are outside scope. Resend parity remains incomplete.

## Brand Commitments

Cloudmail. The user confirmed a professional developer console inspired by Resend: separate function URLs, sidebar navigation, wide lists and compact forms, built directly in code.

## Accessibility & Inclusion

WCAG 2.2, keyboard navigation and responsive desktop/mobile layouts are project requirements.
